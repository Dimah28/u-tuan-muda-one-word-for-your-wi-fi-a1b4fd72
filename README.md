A deterministic program that writes one word describing home Wi-Fi to `/output/entry.txt`.

> Ghosted

## Run it

```sh
python3 main.py
```

The program writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13 standard library only — no network, no randomness, same bytes on every run.
